# Flexbox Playing Cards 🃏

This is my solution for the playing cards practice project from the **Responsive Web Design** course on [freeCodeCamp](https://www.freecodecamp.org/).

## 🎯 Project Objective
The goal of this lab is to demonstrate proficiency with **CSS Flexbox**. The layout was built to fulfill all the *User Stories* required by freeCodeCamp, including:
- Using `display: flex` to horizontally align the cards, allow them to wrap, and manage spacing (`gap`).
- Using `justify-content: space-between` to structure the inside of the cards.
- Using the `align-self` property to correctly position values and suits (top-left, centered in a column, and bottom-right rotated).

## 🛠️ Technologies Used
- HTML5
- CSS3 (Focus on Flexbox)
